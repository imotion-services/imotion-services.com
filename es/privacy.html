Política de privacidad

Última actualización: 29 de octubre de 2026

1. Responsable del tratamiento

El responsable de este sitio web es iMotion Informatikai Kft., 1112 Budapest, Kányakapu köz 6. B. ép., Hungría. Para cualquier cuestión de protección de datos, escríbanos a ceo@imotion-services.com.

2. Ninguna recogida de datos en este sitio web

Este sitio web es un sitio informativo estático. No tiene formularios de contacto, ni suscripción a boletines, ni cuentas de usuario, y no utiliza cookies, almacenamiento local, analítica, píxeles de seguimiento ni ninguna otra tecnología de seguimiento. Las fuentes y todos los demás recursos se sirven desde este mismo sitio web; no se cargan recursos de terceros.

3. Alojamiento y registros del servidor

El sitio web está alojado en GitHub Pages (GitHub, Inc., EE. UU.). Cuando visita el sitio, GitHub trata datos técnicos de conexión, como su dirección IP, para servir las páginas y mantener la seguridad del servicio. No tenemos acceso a estos datos ni los utilizamos. La base jurídica es nuestro interés legítimo en operar un sitio web seguro (art. 6.1.f RGPD). Para más información, consulte la GitHub General Privacy Statement.

4. Contacto por correo electrónico

Si nos escribe a ceo@imotion-services.com, tratamos su dirección de correo electrónico, su nombre y el contenido de su mensaje únicamente para responder a su consulta. La base jurídica es la gestión de su solicitud (art. 6.1.b RGPD) o nuestro interés legítimo en responder a la correspondencia (art. 6.1.f RGPD).

Su mensaje no se comunica a terceros, salvo a nuestro proveedor de correo electrónico, que lo trata por cuenta nuestra: Google LLC (Google Workspace). Eliminamos la correspondencia cuando ya no es necesaria, salvo que existan obligaciones legales de conservación.

5. Sus derechos

En virtud del RGPD, tiene derecho de acceso, rectificación, supresión, limitación del tratamiento, portabilidad de los datos y oposición (arts. 15–21 RGPD). Para ejercer estos derechos, escriba a ceo@imotion-services.com.

6. Derecho a presentar una reclamación

Puede presentar una reclamación ante la Autoridad Nacional de Protección de Datos y Libertad de Información de Hungría (Nemzeti Adatvédelmi és Információszabadság Hatóság, NAIH), 1055 Budapest, Falk Miksa utca 9–11., www.naih.hu, o ante la autoridad de control de su Estado miembro de la UE.

7. Cambios

Actualizamos esta política si cambian el sitio web o nuestros tratamientos. La versión vigente se publica siempre en esta página.
